# 🧠 百科知识大闯关

网页版知识百科答题闯关游戏：内置 200 道小学 AI + 百科知识题，每关 5 道选择题，**全部答对才能进入下一关**，答错则本关重新挑战，边玩边学。

## 核心功能

- **闯关玩法**：每关 5 道选择题，全对过关；答错显示正确答案与解析并重来
- **内置题库**：40 关共 200 题（桌面文档《小学AI+百科知识题库》导入 + 补全），覆盖 AI 常识（提示词、AI 应用、隐私安全、AI 伦理）与百科知识（天文地理、生物科学、历史文化、生活常识），其中单选 116 道 + 判断 84 道（以「正确/错误」形式呈现）
- **学习模式**：浏览全部题目（按关卡切换），**答案默认隐藏**，点击「显示答案」即展开正确答案与解析，适合先复习再闯关
- **进度持久化**：关卡进度 / 已解锁关卡自动保存（SQLite），支持一键重置
- **答案解析**：每道题附带解析，答对答错都会展示，寓教于乐
- **即时反馈**：HTMX 无刷新交互，答完立刻出结果
- **音效反馈**：Web Audio 实时合成音效，答对 / 答错 / 过关 / 大满贯各有专属提示音，无需任何音频文件
- **炫酷科技感 UI**：深空星空背景、霓虹渐变标题、发光按钮与进度条，答对 / 答错 / 过关各有专属动效

## 技术栈

FastAPI + HTMX + Alpine.js + Tailwind CSS（FHAT），SQLite + SQLModel，零 Node 依赖。

## 运行方式

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问 `http://localhost:8000` 开始闯关。

> 提示：首次启动自动建表并写入内置题库。改 schema 后删除根目录 `app.db` 再启动即可重建。

## 关卡结构

- 题库 200 题，每关 5 题 → 40 关，每关恰好 5 题
- 题目按文档顺序分关：AI 单选 → 百科单选 → AI 判断 → 百科判断
